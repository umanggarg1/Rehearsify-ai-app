## 🔴 Critical — security

- [x] **Secrets shipped to the browser.** `NEXT_PUBLIC_DRIZZLE_DB_URL` / `NEXT_PUBLIC_GEMINI_API_KEY`
  were in the client bundle — anyone could read/write the DB and drain the Gemini quota.
  **Done** (commit `2059a78`): renamed to `DATABASE_URL` / `GEMINI_API_KEY` (no prefix),
  `utils/db.js` + `utils/GeminiAIModel.js` are `import "server-only"`, all DB/AI moved into
  `utils/actions.js` server actions. Verified no secrets in `.next/static`.
  _Remaining: rename + rotate the same vars in the Vercel dashboard (see TODO.md S6)._
- [x] **`/api/fetchUserData` has no auth** (T20). Trusted a `userEmail` in the POST body.
  **Done** (`2059a78`): route deleted; replaced by `getUserAnswers` action which derives the
  email from the Clerk session and takes no input.
- [x] **No rate limiting on the AI endpoints** (T21). **Done**: `checkAiRateLimit(email)` in
  `utils/actions.js` gates `createInterview` + `saveAnswer` at 10/min, 60/hour per user
  (in-memory). _Upgrade to Upstash Ratelimit / Redis for multi-instance production._

## 🟠 High — data model & correctness

- [ ] **Timestamps are `varchar "DD-MM-YYYY"`** (`utils/schema.js`) — can't sort, range-query,
  or show "2 hours ago". Switch `createdAt` to `timestamp with time zone` + `defaultNow()`.
  Also drop `moment` (~230 kB) for `date-fns` or `Intl.DateTimeFormat`.
- [ ] **No referential integrity.** `userAnswer.mockIdRef → MockInterview.mockId` is app-level
  only, and `mockId` isn't `unique`. Add a real FK + unique constraint (needs a migration).
- [~] **"Improvement Rate" metric is meaningless.** `(max−min)/min·100` after sorting — throws
  away chronology. T7 only guarded the `Infinity%` case. Real fix: first-half vs second-half
  average by `createdAt`, or drop the card. (Blocked on the timestamp fix above.)
- [~] **Brittle AI JSON parsing.** `GeminiAIModel.js` now sets
  `responseMimeType: "application/json"` and `actions.js` regex-extracts + `JSON.parse`s.
  Still missing: a `responseSchema` and **Zod** validation of the parsed shape, for both
  question generation and feedback.
- [~] **Redundant fetching.** Old `/api/fetchUserData` + `InterviewList`'s own query is gone.
  Dashboard now calls `getUserAnswers` and `InterviewList` calls `getInterviewList` — two
  server round-trips for related data. Could consolidate into one `getDashboardData` action.
- [ ] **`createdBy` vs `userEmail`.** `MockInterview` uses `createdBy`, `userAnswer` uses
  `userEmail`. Pick one name across the schema.
